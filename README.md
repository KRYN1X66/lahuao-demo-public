Lahuao Demo - Public Static Preview

This is a static, client-only preview site deployed to GitHub Pages for quick mobile viewing. It does not connect to your private backend or database — all actions are simulated locally in the browser.

How to use
- Open the site on your phone. Change the username, click "生成模拟卡密" to create a local mock code, "模拟兑换" to credit local balance, and "开箱" to see the wheel animation and simulated drop.

Notes
- This preview is read-only and safe for public access.
- For a full interactive demo connected to your private backend, run the private repository locally or deploy a backend-backed staging environment.
